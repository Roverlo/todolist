## 实现与数据边界

Rust 单一工作线程持有 aria2 子进程和下载日志；仅监听本机回环地址，JSON-RPC 使用 Windows BCrypt 生成的随机令牌。进度不进入任务/随记 Zustand 数据，也不触发其保存。切换页面、窗口隐藏到托盘不会停止下载。显式退出时暂停并写入续传控制文件；`--stop-with-process` 让引擎在父进程意外结束后退出。

`Documents/ProjectTodo/downloads/history.json` 独立保存下载记录和设置，临时文件写入、刷盘、重命名，写入失败保留原文件并提示。引擎释放在同目录 `engine-<版本>/`，默认文件保存到系统 Downloads/ProjectTodo；用户可选择其他绝对目录。测试数据目录覆盖同时隔离引擎、日志及默认下载目录。

下载日志不属于现有“任务/随记备份”或云同步内容，避免将本机绝对路径、下载链接及大文件同步到其他设备。需要迁移下载时，退出应用后同时复制 `downloads/history.json`、实际文件及同目录的 `.aria2` 控制文件，保留原保存路径。手工修改路径不在自动迁移范围内。

断点续传取决于服务器 Range 支持及有效链接。缺少 `.aria2` 控制文件且已有同名文件时拒绝恢复，不猜测文件归属。自动命名遇到已有文件、续传文件或下载记录时添加 ` (1)` 等后缀，保留已有文件；手动指定名称冲突时仍提示修改。移除记录停止任务并保留已下载文件，不自动运行任何下载文件。仅支持普通链接，不处理登录、Cookie、网盘网页或浏览器接管。

粘贴有效链接后自动预览文件名和大小；新建下载时 Rust 为未指定名称的任务独立解析，用户可以直接粘贴后点“开始下载”，不必等待预览。依次使用服务器 `Content-Disposition`（优先 UTF-8 `filename*`）、重定向后的 URL 路径、原 URL 路径，均无合法名称则使用 `download.bin`。查询参数不进入文件名，拒绝路径和 Windows 保留名称。HEAD 不支持或未返回文件名时尝试一个字节的 GET Range，仅读取响应头后丢弃正文；服务器不支持预识别时仍允许开始下载并自动命名。预览结果不覆盖重命名输入，也不能用旧链接的延迟响应覆盖新链接。HEAD 大小从响应头读取，不使用空正文的长度。浏览器预览可显示 URL 中的名称，但受浏览器网络跨域限制，不执行原生服务器识别或真实下载。带签名或密码参数的实际链接只用于本地验证，不进入源码、提交或公开报告。

设置：同时下载 1–8 个文件，总限速单位 KiB/s，0 表示不限速；这两项保存后立即作用于当前引擎。单文件连接数支持 1、4、8、16、32、64，默认沿用此前的 4；旧日志缺少该字段时自动使用 4。新任务、重试和重启恢复使用当前值；已有任务可暂停再继续应用新值。该值同时传给 aria2 的 `split` 与 `max-connection-per-server`，表示上限，实际连接数量受 Range 支持、文件大小及服务器限制影响，更多连接不保证更快。保留引擎默认最小分片 20 MiB，小文件可能仅用单连接。保存目录仅影响新任务。完成通知使用已有 Tauri 通知插件，其展示受系统通知设置影响。
