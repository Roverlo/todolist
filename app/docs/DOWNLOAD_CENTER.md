## 实现与数据边界

Rust 单一工作线程持有 aria2 子进程和下载日志；仅监听本机回环地址，JSON-RPC 使用 Windows BCrypt 生成的随机令牌。进度不进入任务/随记 Zustand 数据，也不触发其保存。切换页面、窗口隐藏到托盘不会停止下载。显式退出时暂停并写入续传控制文件；`--stop-with-process` 让引擎在父进程意外结束后退出。

`Documents/ProjectTodo/downloads/history.json` 独立保存下载记录和设置，临时文件写入、刷盘、重命名，写入失败保留原文件并提示。引擎释放在同目录 `engine-<版本>/`，默认文件保存到系统 Downloads/ProjectTodo；用户可选择其他绝对目录。测试数据目录覆盖同时隔离引擎、日志及默认下载目录。

下载日志不属于现有“任务/随记备份”或云同步内容，避免将本机绝对路径、下载链接及大文件同步到其他设备。需要迁移下载时，退出应用后同时复制 `downloads/history.json`、实际文件及同目录的 `.aria2` 控制文件，保留原保存路径。手工修改路径不在自动迁移范围内。

断点续传取决于服务器 Range 支持及有效链接。缺少 `.aria2` 控制文件且已有同名文件时拒绝恢复，不猜测文件归属。新建时拒绝同名文件和记录；移除记录停止任务并保留已下载文件，不自动运行任何下载文件。仅支持普通链接，不处理登录、Cookie、网盘网页或浏览器接管。

新建下载离开链接输入框时会识别服务器 `Content-Disposition` 文件名和 `Content-Length` 文件大小，也可手动点击“识别文件”。优先 UTF-8 `filename*`，拒绝文件名中的路径和 Windows 特殊字符；识别结果不覆盖用户手动填写的名称。HEAD 不支持时只请求一个字节的 Range 响应头，HEAD 大小从响应头读取，不使用空正文的长度。识别失败可手动填写文件名继续下载。带签名或密码参数的实际链接只用于本地验证，不进入源码、提交或公开报告。

设置：同时下载 1–8 个文件，总限速单位 KiB/s，0 表示不限速；修改立即作用于当前引擎。保存目录仅影响新任务。完成通知使用已有 Tauri 通知插件，其展示受系统通知设置影响。

- 压缩包 SHA-256：`579f17351e81c9fe3ed11d9700f5983235fc362beaf20f5f02820f7a1bfe49b0`。
- 引擎 EXE SHA-256：`b7edee5c43ff18b9e8b77983033ba7816fa220d810949d81fdb928e8b36d862f`。
- 来源锁定到 [上游发布](https://github.com/motrixapp/aria2/releases/tag/v1.37.0-motrix.16)；校验值对应 Motrix 提交 `991477f6e735e3cf8d394a0b7da859b1e91b687d` 的 `scripts/engine.lock.json`。
