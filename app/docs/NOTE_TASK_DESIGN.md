## 前导空行修正（2026-09-22）

第一条待办开头按 Backspace 时，先删除同一容器内紧邻列表的空段落，保留待办；在前面的空段落按 Delete 也可删除空行。Ctrl 组合键行为一致，连续空行逐次删除，支持撤销、重做和保存重开。只在用户执行删除时处理，不自动清理笔记中的空行。

此规则优先于默认列表提升和空待办删除。非空正文沿用原有编辑行为；引用及表格单元格内局部处理，不跨容器。父待办所必需的首段落保留，避免损坏子项结构。

用户报告确认了问题及期望；上述键盘细节是本轮实现选择。专项检查见 `scripts/check-note-leading-blank.mjs`，本轮执行结果记录在本机 `app/ui-check.local/leading-blank-20260922/REPORT.md`，不将修复等同于用户已验收。

## 重复排序及创建时间（2026-09-28）

- 用户反馈：点击“未完成在前”后又勾选部分待办，再点同一个按钮应重新排列，无需先切到“已完成在前”。确认每次点击使用当前状态；勾选本身不自动移动待办。
- 已复现原因：光标留在子待办或另一父项下时，勾选其他待办后仍按旧光标层级排序。修正为勾选后将光标定位到被操作待办；保留同级排序、父子整体移动、引用和单元格隔离。真正已经有序时仍提示无需调整，不新增撤销历史。
- 用户补充：“我们之前完成待办任务的时候，才会加时间戳。我希望写任务的时候也加”。确认新建随记待办时记录创建时间，完成时间独立记录。旧待办无法还原创建时间，不在打开、编辑、勾选或排序时补造。
- 初版实现选择（被下方同日反馈替代）：完成后只显示完成时间，创建时间放在悬停提示中。当前改为同时显示两项时间；两项时间作为 HTML 属性保存，不进入正文或字数。
- 新建、回车和 `[ ] ` 快捷输入生成新创建时间；缩进、移动、撤销/重做及带元数据的 HTML 往返保留时间。导入无创建时间的旧 HTML 不补造。周报素材区分创建与完成时间，不改统计区间和随记筛选规则。
- 验证入口：`check-note-task-creation.mjs`、`check-note-task-sort.mjs` 经 `test-note-completion.mjs` 同时支持生产浏览器和隔离原生数据；周报请求经 `test-weekly-report.mjs` 验证。最终通过及未运行项记录在本机 `app/ui-check.local/task-fixes-20260928/REPORT.md`；不将源码修复等同于已发布 EXE。
